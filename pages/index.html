Your tickets and documents in Git, right where you work, not buried in a cloud.

An open-source agile system: Kanban boards, sprints, roadmaps, documents and ideas, all plain markdown in your own repositories. Works with your AI tools, and just as well without them.

Install View on GitHub

Status is the folder

A ticket is a markdown file. Its column is the folder it's in, and moving it is a git mv, so git history is your audit trail.

It lives where you work

A tickets repository beside your code. No server, no database, no account, and nothing to pay for. Your team and your AI read the same files.

One set of rules

amd on the command line and amdui on the desktop share one library, so a move follows the same rules wherever it's made.

Features

Tickets

  • One flexible ticket, from templates you can change
  • Priority, points, assignee, tags and repository
  • Typed links (requires, related, parent, supersedes) and a tree of them
  • Save and New for a ticket that depends on one not made yet
  • Drafts that can't leave the backlog until ready
  • A git branch per ticket when work starts
  • Search and filters

Workflow rules

  • One column at a time, unless the team allows other moves
  • Your own columns: Triage, Review, Released and more
  • Done waits for what a ticket requires and its children
  • A WIP limit on doing
  • Locks while a ticket is being worked on
  • Every change committed and pushed, boards kept in step

Planning

  • Epics and sprints, both optional
  • Auto priority from requires links, and a what's-needed-first sort
  • Roadmaps with milestones, working days and time left
  • My work across every project on your machine

Documents and ideas

  • ADRs, RFCs and docs in a documents repository
  • Rich-text editing, history, restore and search
  • A pinned start page per project
  • Ideas with votes and notes, one click to a ticket

Teams

  • amd init and amd join set a project up
  • Several repositories per project, several projects
  • New repositories made from the ticket that needs them
  • Team settings for admins; your own preferences
  • GitHub issues arrive as tickets to triage
  • Deleted tickets recovered from history

The desktop board

  • Drag and drop, with the rules shown as you drag
  • Live: changes from anywhere appear in a second
  • A terminal and an AI tab in a bottom panel
  • Optional speech to text, entirely on your machine
  • Themes, accent colours and zoom

AI, if you want it

  • amd mcp for Claude Code, Copilot, Cursor, Codex, Gemini CLI and more
  • Reads the board, documents, ideas and what's on screen
  • Changes tickets under the same rules, every change committed
  • No API keys, nothing runs unless your AI tool starts it

Command line

  • Everything the board does is a command
  • Safe in scripts and CI: never prompts without a terminal
  • Shell completion for bash, zsh and fish

A look around

Install

On Linux or macOS, with git 2.29 or later and Rust. The desktop board also needs Trunk, the wasm32-unknown-unknown target, and on Linux WebKitGTK and ALSA (libwebkit2gtk-4.1-dev libasound2-dev).

git clone https://github.com/agile-md/amd.git
cd amd
bash install.sh --from-source

That installs amd and amdui, and on Linux adds the board to your application menu. Then start a project:

amd init my-project       # makes my-project-tickets and my-project-documents on GitHub
amd new "My first task"
amdui                     # the desktop board

Prebuilt downloads come with the first release.
